# Quick Menu

The Hitfel 5 is equipped with an ease of access Home Menu which allows for simple intuitive quick buttons. To activate it, just press the **H** key.

You'll find the following buttons in the Quick Menu

* Home Button: Exits the app and takes you to the Home Menu
* Wi-Fi Button: Connects to the Wi-Fi Module to check if there's a connection
* Time: A 24-hour/military time clock
* Power Button: Shuts down the console
* Sleep Button: Puts the console in sleep mode
* Battery: Checks the battery percentage of the console
* Save Button: Saves the console's state to a ProAccount key or ProFS Capsule
* Lock Console Button: Locks or unlocks the console for 3 minutes.
* System Settings Shortcut Button: Opens system settings
