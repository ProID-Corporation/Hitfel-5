# Aurora

## Aurora Virtual Assistant

Aurora is the virtual assistant built into Hitfel 5. Her features, interface, and system access depend on the installed version of Hitfel 5.

| Aurora version | Hitfel 5 version        |
| -------------- | ----------------------- |
| Aurora 1.0     | Version 4.2 and earlier |
| Aurora 2.0     | Version 5.0 and later   |

### Accessing Aurora

Both versions of Aurora are accessed through the same location:

1. Go to the **Main Menu**.
2. Select **Aurora**.

Commands are typed into the textbox provided by Scratch.

### Aurora 1.0

{% hint style="info" %}
Aurora 1.0 is available in Hitfel 5 Version 4.2 and earlier.
{% endhint %}

#### Interface and Requirements

Aurora 1.0 does not have a dedicated visual menu. Users must turn up their device volume to hear and understand her spoken responses.

Most commands require an internet connection.

#### Supported Commands

The following list describes supported actions. Exact command wording may vary.

| Command or action          | Function                                        |
| -------------------------- | ----------------------------------------------- |
| Open the loaded app        | Opens the currently loaded app.                 |
| Turn off                   | Turns off the console.                          |
| Back up data from Hitfel 3 | Provides the backup function for Hitfel 3 data. |
| Factory reset              | Performs a factory reset.                       |
| Console info               | Provides information about the console.         |
| What time is it            | Tells the user the current time.                |
| Credits                    | Provides the credits.                           |
| Set passcode               | Sets a passcode.                                |
| Change passcode            | Changes the passcode.                           |

#### System Access

Before the Settings app was introduced in Hitfel 5 Version 3.0, Aurora handled system-setting commands.

Aurora 1.0 could perform system-level actions, including factory resetting the console and disabling the internet module.

### Aurora 2.0

{% hint style="info" %}
Aurora 2.0 is available in Hitfel 5 Version 5.0 and later.
{% endhint %}

#### First-Time Setup

Before Aurora 2.0 can be used, users must enter their name for her memory system. Aurora remembers this name so she can greet and address the user.

Once setup is complete, users can enter commands through the Scratch textbox.

#### Interface and Requirements

Selecting Aurora opens a menu with an animation. Aurora also reacts to commands.

Captions allow users to follow her responses without turning on their device volume. None of Aurora 2.0’s commands require an internet connection.

#### Supported Commands

| Command or action            | Function                                                                                      |
| ---------------------------- | --------------------------------------------------------------------------------------------- |
| Open settings                | Opens the System Settings app.                                                                |
| Open the loaded app          | Opens the currently loaded app.                                                               |
| Open the OnTags app          | Opens OnTags.                                                                                 |
| Open +app                    | Opens +app.                                                                                   |
| Check the battery            | Checks the device battery.                                                                    |
| Put the device in sleep mode | Puts the device into sleep mode.                                                              |
| Chat with Aurora             | Supports conversations, including questions about favorite movies, foods, and ProID products. |
| Ask about a ProID product    | Provides information about any ProID product.                                                 |
| Reset Aurora’s memory        | Takes the user to settings to reset her memory.                                               |

#### System Settings and Memory

Aurora 2.0 no longer changes system-level settings such as factory resetting the console or disabling the internet module. These functions are managed through the **System Settings app**.

Aurora can open the System Settings app and direct users there to reset her memory.

### Version Comparison

| Feature               | Aurora 1.0                       | Aurora 2.0                              |
| --------------------- | -------------------------------- | --------------------------------------- |
| Access                | Main Menu → Quick Icon           | Main Menu → Quick Icon                  |
| Command input         | Scratch textbox                  | Scratch textbox                         |
| Visual menu           | No dedicated menu                | Animated menu                           |
| Command reactions     | Not specified                    | Available                               |
| Captions              | Audio required                   | Available                               |
| Internet requirement  | Required for most commands       | No commands require internet            |
| Name memory           | Not specified                    | Required during initial setup           |
| System-level settings | Can change system-level settings | Opens Settings for users to manage them |
